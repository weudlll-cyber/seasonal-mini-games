# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Include what is affected, how to reproduce it, and the impact you expect. Reports in English are preferred.

## What happens next

- Triage within 7 days of the report: you get an answer whether the issue is accepted.
- Fix targets after triage: critical within 7 days, high within 30 days (Bingo 03 §18, adopted in [05 §1](docs/spec/05-security-threat-model.md)).
- Fixes ship in a new release; the advisory is published once the fix is available.

## Supported versions

Only the latest release receives security fixes.

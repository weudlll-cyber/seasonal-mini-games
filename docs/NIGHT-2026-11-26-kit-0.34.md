**Why the three small controls of the Mind Games result came so late** (`e2e/sweepScreens.ts`, `matchesOf` and `resultOf`): run 1 left Mind Games' series at its defaults, so it moved on to the next round; run 2 gave it one round, so ending that round ended the match ("Match over"); run 3 gave it two rounds with a 120 s pause and ended the round only once, and the 28 looks took longer than the pause. The settings are now ten long rounds (line 123) and `resultOf` (line 206) ends the round again whenever the page shows one running. Behind all of it: the kit's sweep ends at the first screen that does not open (`dist/testing/sweep.js:25` inside the loop at lines 54 to 56), hiding every later screen. `e2e/sweep.spec.ts:28` (`sweepAll`) now sweeps screen by screen and reports all at the end, and `showRound` (`sweepScreens.ts:173`) takes a new round when a bot ended one, so the first run of a chain collects every finding. These two harness changes were type-checked and linted only; the draft PR's CI run is their first run.

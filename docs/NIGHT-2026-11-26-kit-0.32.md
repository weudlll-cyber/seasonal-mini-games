## For the kit planning

- `SeasonIcon` takes a size in pixels only and has no one-colour (mask) form, so a game whose icons follow the font size or a fitted scale cannot use it (T434).
- ADOPTION names only the player app's `shell/http.ts`; the admin app's client has a step-up retry that `createApiClient` has no place for (T434).
- `db-roles.sql` revokes TEMPORARY from PUBLIC and grants it to nobody: a migration that makes a temporary table fails for the owner (Mini Games' 0011 did on a fresh database). The game grants it after the script (T436).
- `securityHeaderSet` takes no plain-http address with a path in `frames`, so a plain-http development website falls back to `'self'` (T435).
- The admin command's `restore` passes no `--secrets-to`, so a game whose backup holds secret files needs a verb of its own to put them back on a new server (Mini Games: `smg keys`, T437).
- `findLowContrast` reads written colours only: a game's `var()` references and `color-mix` colours need its own code (T438).

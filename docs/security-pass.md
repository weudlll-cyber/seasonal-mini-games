# Security pass

The results of the security scans of roadmap phase 8 ([spec/11](spec/11-roadmap.md)), newest first. Each pass names its tools with their versions, the commands, every finding with its verdict, and what was fixed. The raw reports are in `reports/`. Where this file sits: [DECISIONS](DECISIONS.md) T106.

## 2026-11-01 — the parts that need no VPS (night run 3, N4)

Branch `night/2026-10-27`; scans against the development servers on one machine. Reports: `reports/security-pass-2026-11-01/`.

### Tools and commands

| Scan                         | Tool and version                                                         | Command                                                                                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Secrets in the whole history | gitleaks 8.30.1 (the image CI uses, `ghcr.io/gitleaks/gitleaks:v8.30.1`) | `gitleaks git /repo --log-opts="--all" --redact --report-format json` over all refs (65 commits with a patch)                                                                |
| Dependencies                 | pnpm 12.14.0 `audit`                                                     | `pnpm audit --json`, `pnpm audit --prod`                                                                                                                                     |
| Lockfile                     | osv-scanner 2.7.0 (the image CI uses)                                    | `osv-scanner scan source --config=osv-scanner.toml --lockfile=pnpm-lock.yaml`                                                                                                |
| Web baseline                 | OWASP ZAP 2.17.0 (`zaproxy/zap-stable`)                                  | `zap-baseline.py -t <url> -J … -r … -I` against the player app (Vite, 5410), the admin app (Vite, 5411) and the Fastify server (3910), whose headers are the production ones |

The ZAP scans of the Vite servers went to their IP address, because Vite answers 403 to the unknown host name `host.docker.internal`.

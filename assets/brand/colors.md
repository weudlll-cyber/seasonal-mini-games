# Season colours

Taken from the Seasonal Entertainment website (`client/src/styles/tokens.css`, 2026-10-19), so the game and the website share one palette. The same values apply in light and dark themes.

| Season | Token (the website's name; the game's is the kit's `--sk-` form) | Hex |
|---|---|---|
| Spring | `--color-spring` (`--sk-color-spring`) | `#afb84e` |
| Summer | `--color-summer` (`--sk-color-summer`) | `#e06e22` |
| Autumn | `--color-autumn` (`--sk-color-autumn`) | `#f9a825` |
| Winter | `--color-winter` (`--sk-color-winter`) | `#04aaf7` |

Text and icons on a season colour use `#12161c` (`--color-on-season` on the website, `--sk-color-on-season` in the game).

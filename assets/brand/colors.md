# Season colours

Taken from the Seasonal Entertainment website (`client/src/styles/tokens.css`, 2026-10-19), so the game and the website share one palette. The same values apply in light and dark themes.

| Season | Token | Hex |
|---|---|---|
| Spring | `--color-spring` | `#afb84e` |
| Summer | `--color-summer` | `#e06e22` |
| Autumn | `--color-autumn` | `#f9a825` |
| Winter | `--color-winter` | `#04aaf7` |

Text and icons on a season colour use `#12161c` (`--color-on-season` on the website).
